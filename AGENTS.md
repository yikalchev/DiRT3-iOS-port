# DiRT 3 iOS port: working notes

This repository builds one thing: a sideloadable iOS app that runs
**DiRT 3** (PS3, title ID `BLES01548`) natively
through the ps3recomp runtime. It started from the MotorStorm port, but all
MotorStorm-specific code, tools and the macOS target have been removed.

## Layout

- `DIRT3/` – Xcode project (single iOS target `DIRT3`, scheme `DIRT3`).
- `port/` – game runner (`main.cpp`), CMake build, launch options
  (`port/ios/dirt3-runtime-options.json`), iOS dependency pins.
- `port/recompiled/`, `port/spu/`, `research/dirt3/` – generated by
  `tools/analyze_dirt3.sh` from `game/`; ignored by Git.
- `vendor/ps3recomp/` – runtime checkout restored by `tools/bootstrap_runtime.py`
  at the commit in `port/ps3recomp-commit.txt` plus `patches/ps3recomp-local.patch`; ignored by Git.
- `scripts/build-dirt3-ios.sh` – the one-command IPA build.

## Rules

- Keep runtime changes in `vendor/ps3recomp` and re-export them with
  `python3 tools/export_runtime_patch.py` so `patches/ps3recomp-local.patch`
  stays the single source of truth.
- Do not commit game files, decrypted executables or generated sources.
- Title-specific behaviour must be keyed to DiRT 3 (image hashes, addresses)
  and documented; do not reintroduce MotorStorm specialisations.
- A successful build is not proof the game works. Report what was verified on
  device (boot, menus, audio, races) separately from what only compiled.
- Session logs are under the app's `Documents/logs/performance/`; pull them
  with `tools/collect_ios_diagnostics.py` (see README).
